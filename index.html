Skip Navigation Link
In this activity, you will add a skip navigation link to the web page to allow screen reader users to jump over any other content that may exist on the page and go directly to the site's navigational controls.
Tab Component
In this activity, you will create a tabbed component where content will only display when a tab is clicked on. Then you will apply ARIA roles and attributes to help improve the accessibility of the component.
